# MultiClient.exe —— 禁用教学管控 patch 点

## 样本
- 文件：`MultiClient.exe`（学生端“多媒体+交互”客户端，接收教师 WebSocket 指令的桥）
- MD5：`b8bb9b809e8f45918f6759d4cb51f5b0`
- 大小：`1189376` B
- PE32 i386，ImageBase `0x400000`

## 背景
MultiClient 接收教师端下发的教学指令并在本地分发执行。三条功能指令链
（屏幕广播 / 键鼠锁 / 行为管控转发）是**异步回调驱动**，静态调用图上无公共
上游 dispatcher，但**每条链的指令入口各只有一个函数**，入口均为 MSVC SEH 序言
`55 8b ec`。将其 patch 为 `31 c0 c3`（`xor eax,eax; ret`）即让该入口函数直接
返回 → “收到指令后不执行任何操作”。

## Patch 点

| 功能 | 入口函数 | VA | file_off | 原字节 | 新字节 | 必需 |
|---|---|---|---|---|---|---|
| 屏幕广播入口 | `FUN_0042f970` | `0x42f970` | `0x2ED70` | `55 8b ec` | `31 c0 c3` | 否（可选） |
| 键鼠锁指令 | `FUN_0041ae10` | `0x41ae10` | `0x1A210` | `55 8b ec` | `31 c0 c3` | 是 |
| 行为管控转发 | `FUN_004197a0` | `0x4197a0` | `0x18BA0` | `55 8b ec` | `31 c0 c3` | 是 |

### 说明
- **屏幕广播入口**（`FUN_0042f970`）：广播唯一入口（→`FUN_0042b3d0` 主循环）。
  设为可选——若改用「屏幕广播窗口化」（见 `screenrender_windowed.md`）保留广播，
  则不封此点；若要彻底禁用广播，勾选即可。
- **键鼠锁指令**（`FUN_0041ae10`）：解析带 `lock` 字段的 JSON（日志 `Lock:%d`）。
  `lock` 是随屏幕广播/黑屏指令搭车下发的协议字段，**非独立功能**，但需单独封
  此 handler，否则广播窗口化后 `lock` 仍生效。
- **行为管控转发**（`FUN_004197a0`）：→`FUN_00418d80`→`127.0.0.1` 回环转发
  DeviceControl（网络 / USB / 程序管控落地）。

## 验证
三点入口字节均为 `55 8b ec`，dry-run 写入 + 读回 + 还原零残留，字节级通过。
